# KNW-002: PartnerSync API のレート制限（過去事故あり）

外部連携先「PartnerSync API」（架空）は**レート制限が厳しい（約 10 req/sec）**。

## 過去事故
リトライが同時集中し、先方から一時的に接続遮断された障害が発生した経緯がある。

## 制約
- 連携呼び出しは必ず**指数バックオフ + ジッター**を実装する
- 即時・固定間隔のリトライは禁止

## 追記 2026-08-10

## 追記: 手動同期とバッチのレート制限カウンタ共有（2026 判明）

PartnerSync 連携において、管理画面からの「手動同期」とバッチ処理は同一のレート制限カウンタを共有していることが判明した。両者が同時実行されると、指数バックオフ等のリトライ制御を入れていても、カウンタ枯渇により即座に 429（Too Many Requests）が返ることがある。

- 手動同期とバッチの同時実行を避ける、または実行前にどちらかが進行中でないかを確認する仕組みが必要
- 既存の「指数バックオフ + ジッター」だけでは、同時実行による即時 429 は回避できない
