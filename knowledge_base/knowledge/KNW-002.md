# KNW-002: PartnerSync API のレート制限（過去事故あり）

外部連携先「PartnerSync API」（架空）は**レート制限が厳しい（約 10 req/sec）**。

## 過去事故
リトライが同時集中し、先方から一時的に接続遮断された障害が発生した経緯がある。

## 制約
- 連携呼び出しは必ず**指数バックオフ + ジッター**を実装する
- 即時・固定間隔のリトライは禁止

## 追記 2026-08-10

手動同期とバッチ処理の間で PartnerSync のレート制限カウンタが共有されていることを確認。両者が同時実行されると、個別には制限内でもカウンタが合算され 429 が発生する事例が確認された。手動同期とバッチの実行タイミングが重ならないよう調整するか、共有カウンタを踏まえた上限設計が必要。
