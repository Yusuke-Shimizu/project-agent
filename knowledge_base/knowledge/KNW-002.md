# KNW-002: PartnerSync API のレート制限（過去事故あり）

外部連携先「PartnerSync API」（架空）は**レート制限が厳しい（約 10 req/sec）**。

## 過去事故
リトライが同時集中し、先方から一時的に接続遮断された障害が発生した経緯がある。

## 制約
- 連携呼び出しは必ず**指数バックオフ + ジッター**を実装する
- 即時・固定間隔のリトライは禁止

## 追記 2026-08-10

手動同期（管理画面からの実行）とバッチ処理は PartnerSync API のレート制限カウンタを共有している。両者が同時に実行されると、共有カウンタが上限に達し即座に 429 が返る事象が確認されている。手動同期とバッチの同時実行を避ける、または呼び出し元で調整（キューイング・排他制御など）する必要がある。
