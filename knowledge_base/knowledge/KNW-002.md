# KNW-002: PartnerSync API のレート制限（過去事故あり）

外部連携先「PartnerSync API」（架空）は**レート制限が厳しい（約 10 req/sec）**。

## 過去事故
リトライが同時集中し、先方から一時的に接続遮断された障害が発生した経緯がある。

## 制約
- 連携呼び出しは必ず**指数バックオフ + ジッター**を実装する
- 即時・固定間隔のリトライは禁止

## 追記 2026-08-12

PartnerSync の手動同期とバッチ処理は、レート制限カウンタを共有している。両者を同時に実行すると 429 が発生する事例が確認されている。バッチと手動同期のスケジュールが重ならないようにするか、共有カウンタを踏まえた上限設計にする必要がある。
