# DEC-005: フロントは React SPA + S3/CloudFront

**決定日**: 2025-10 / **状態**: active

## 決定
フロントエンドは React による SPA とし、S3 + CloudFront で静的配信する。SSR は採用しない。

## 理由
- 管理画面主体でSEO要件が薄く、SSRの運用コストに見合わない
