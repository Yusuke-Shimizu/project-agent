# DEC-006: IaC は AWS CDK (TypeScript) に統一

**決定日**: 2025-11-06 / **状態**: active

## 決定
インフラ定義は AWS CDK (TypeScript) に統一する。CloudFormation テンプレの直書きや Terraform との混在は禁止。

## 理由
- 言語・レビュー・CIを一本化し、構成のばらつきを防ぐ
