# DEC-001: 認証基盤に Amazon Cognito を採用

**決定日**: 2025-06-12 / **状態**: active

## 決定
ユーザー認証・認可基盤に Amazon Cognito を採用する。

## 理由
- 自前の認証実装を避け、SAML/OIDC 連携（顧客IdP接続）を標準機能で満たせる
- テナント数拡大時のスケールとコストが読みやすい

## 却下した案
- 自前JWT実装 → 保守負担とセキュリティリスクで却下
