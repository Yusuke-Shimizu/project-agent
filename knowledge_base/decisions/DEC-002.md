# DEC-002: 主データストアは Aurora PostgreSQL（DynamoDB不採用）

**決定日**: 2025-07 / **状態**: active

## 決定
主データストアは Amazon Aurora PostgreSQL とする。DynamoDB は主データストアには採用しない。

## 理由
- 在庫集計・引当のロジックが複雑な JOIN と整合性を要求する
- DynamoDB の単一テーブル設計では在庫の横断集計クエリが表現しづらい

## 補足
- セッションやキャッシュ等の用途で DynamoDB を併用することは否定しない（本決定は「主データストア」に関するもの）
